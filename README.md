# Background-Apps-Tracker

A lightweight AI-powered Windows monitoring tool that tracks currently running background applications and displays them in real-time through the Command Prompt (CMD).

## Features

* Detects running background processes on Windows
* Real-time process monitoring
* Command-line interface for quick access
* Lightweight and fast execution
* AI-assisted process tracking and analysis
* No complex setup required

## How It Works

The application continuously scans the system for active background processes and displays the detected applications directly in the Command Prompt window.

Example output:

```text
[INFO] Scanning background applications...

chrome.exe
discord.exe
spotify.exe
explorer.exe
steam.exe

Total Background Applications: 5
```

## Requirements

* Windows 10/11
* Python 3.8+ (if running from source)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/Background-Apps-Tracker.git
```

2. Navigate to the project directory:

```bash
cd Background-Apps-Tracker
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
python main.py
```
